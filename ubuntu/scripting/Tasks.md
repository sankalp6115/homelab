# Homelab Ubuntu Scripting Tasks

Control Layer Features ported to Ubuntu:

- [x] status - Full dashboard (CPU, RAM, storage, battery, temperature, services, network, ports)
- [x] storage - Root partition storage report
- [x] battery - Linux sysfs / upower / AC power battery status
- [x] wifi - Network connection & link speed report (WiFi / Ethernet)
- [x] ports - Python processes listening with `--port`
- [x] update - Git repository sync
- [x] app-list - Table of apps with running/stopped status
- [x] app-status - Status of individual app
- [x] app-up - Launch app
- [x] app-down - Stop app
- [x] app-restart - Restart app
- [x] app-logs - Attach to tmux session
- [x] music-sync - rclone sync for songs + library database sync + tmux restart
- [x] backup - GitHub mirror backup script
